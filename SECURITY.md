# Security reports

Report suspected vulnerabilities privately to [info@qcloud.host](mailto:info@qcloud.host). Include the affected example or SDK revision, a short reproduction and potential impact. Do not include live credentials, customer data or attack traffic against other accounts.

If you expose an API key, revoke it in your QCloud workspace and create a replacement. Removing it from a file or issue does not revoke the key.

These examples run on a trusted server or developer machine. They are not a browser credential proxy or a production deployment template. Tests replace the HTTP transport and use synthetic credentials and inputs.
